# Resources by calendar week

Generated 2026-08-24. Ranks 1807 scraped resources against each calendar week's theme, hooks and outlines using BM25 over the resource's title, description, tags and full scraped text where available. Each week's query is first pruned to its distinctive vocabulary (words not shared by most of the other 100 weeks' templated hook/outline phrasing), so matches reflect the week's actual topic rather than boilerplate instructional language common to every week. Top 12 matches per week, floor score 1.0, each resource allocated to at most 2 of its best-fit weeks so broad-vocabulary pages (blog indexes, course landing pages) do not recur in every week's list.

Source corpus: `mlsource/data/all_resources.json` + `mlsource/resources/content/`. Regenerate with `python3 tools/build_topic_index.py` whenever the calendar or the corpus changes; this file is a derived artifact, not hand-edited.
